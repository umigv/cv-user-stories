# cv-user-stories
Collection of user stories for computer vision. For project tracking

Generally user stories are 2 weeks long and denote a small project or small chunck of a larger project.
Spec sheets are high level overviews of projects that are longer than 2 weeks long. They help keep the project scope on track.
To create a user story / spec sheet go to the issues tab, use a respective spec sheet or user story template and fill it out. Make sure to add it to our CV Project Team project!
Eventually new user stories will to be presented during sprint planning and reviewed during sprint reviews.
